# MEGEE Container Planner v3

面向订单与现场执行的集装箱装柜生产力工具。应用只保留两个工作区：`装柜规划`与`装柜方案库`。产品与包装参数由当前方案直接录入；方案库只保存用户实际计算并明确保存的版本。

## 核心能力

- 订单量规划：严格保持各 SKU 输入数量，按 `ceil(EA ÷ EA/BOX)` 计算箱数，尾箱占完整箱位、置顶、禁止承压。
- 柜容反算：支持固定数量、范围可调数量、同组齐套组件数量；每个候选组合都必须通过真实纸箱/托盘排布和几何审计。
- 包装方式：逐 SKU 选择纸箱或托盘。纸箱高度固定向上、底面允许 90° 旋转；托盘显示单托排箱、层数、总高、边界及外伸。
- 标准柜型：20GP、40GP、40HQ。
- 多视图：俯视、纵向侧视、箱门端视；托盘 SKU 另有托盘排箱视图。
- 报告：同一计算快照生成中英文 HTML 装柜报告、打印/另存 PDF 与 Packing List PDF。
- 方案治理：本机方案库、草稿/已确认状态、修订号、搜索、排序及表头漏斗筛选。
- 分享：仅在用户主动操作时生成一个方案的短链接；不会公开本机完整方案库。

默认外箱为 480 × 380 × 350 mm，默认托盘为 1000 × 1200 × 150 mm；EA/BOX 与产品数量不设业务默认值。

## 数据边界

公开版本不含 Cost 系统接口、企业产品快照、Excel 批量预规划、成本、BOM 或客户数据。输入和方案库默认保存在当前浏览器；只有用户主动创建网页分享时，所选方案快照才写入分享存储。

## 本地运行

要求 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开 <http://localhost:3000>。

## 质量门槛

```bash
npm run lint
npm test
npx wrangler deploy --dry-run
```

详细验收标准见 [ACCEPTANCE.md](./ACCEPTANCE.md)，架构边界见 [ARCHITECTURE.md](./ARCHITECTURE.md)。

## 部署

- 正式入口：<https://container.lostravelerk.com/>
- GitHub 与 Cloudflare 发布必须指向相同提交。
- 页脚、装柜报告与 Packing List 同时显示应用版本、算法版本和源码短提交号。

当前算法是经过边界、间隙、高度、门洞、重叠、箱数、EA 与 CBM 审计的工程规划工具；最终执行仍需现场确认纸箱抗压、托盘承载、总重量、轴载、重心、系固及实测尺寸。
