# 浙江美集实业有限公司 · 集装箱装柜规划

一个本地优先的可视化装柜计算工具。最大包装单元可选择纸箱或托盘，支持尺寸、公差、安全空隙和多剖面查看。

## 功能

- 最大包装单元：纸箱 / 托盘
- 美集默认纸箱：480 × 380 × 350 mm
- 默认托盘：1000 × 1200 × 150 mm
- 20GP、40GP、40HQ 与自定义集装箱内部尺寸
- 20GP、40GP、40HQ 三种柜型同步对比；40HC 作为 High Cube 的同义缩写统一显示为 40HQ
- EA/BOX 可选输入（无默认值），输入后同步换算总 EA
- 标准 Excel 导入字段：系列、产品代码、品名规格、产品数量、EA/BOX、外箱尺寸、包装方式、托盘尺寸；兼容旧模板“家族”和“品名”表头，外箱空白自动采用美集默认 480 × 380 × 350 mm，导入后自动生成全部产品的三种柜型方案
- 支持两种明确输入方式：Excel 批量导入并自动进入方案库，或手工单笔填写后即时计算、保存和出报告
- 支持多产品拼柜：可手工添加 SKU，或先选系列再选择“产品代码 · 品名”并锁定自动带出的主数据；本次产品数量保持可编辑，系统自动计算总箱数、尾箱数量并在超出一柜时完整分柜
- 支持“项次 / Item Group”齐套采购：齐套状态只比较同项次 SKU 的产品数量 PCS 是否相等；产品数量可为任意正整数，各 SKU 箱数按 `ceil(PCS ÷ EA/BOX)` 独立计算并保留尾箱。齐套不一致只显著提醒、不阻断装柜、托盘排箱、分享或 PDF；N 柜组合推荐仍逐案调用真实装柜算法复核
- 拼柜采用紧凑 SAP 列表 + 当前 SKU 参数区：列表负责高频业务录入和计算结果，EA/BOX、外箱、托盘、外伸及装柜余量集中在参数区，避免超宽表格同时保留逐 SKU 独立参数
- 多产品默认允许相邻 SKU 在地面空余轮廓内交错补位，但任何实体包装绝不重叠并始终保留 SKU 间隙；分批卸货或需要严格分区时可关闭交错优化
- 每个 SKU、每个集装箱及整单均显示 CBM 材积；纸箱按完整外箱位计算，托盘按托盘外廓与实际组托总高计算，尾箱仍占一个完整箱位
- 产品方案库支持检索、人工备注、保存方案版本、重新打开和直接查看客户报告
- 产品方案库的 20GP、40GP、40HQ 每格同时显示纸箱数 BOX 与成品数量 EA
- 公开版本不内置任何企业产品快照；客户可下载空白模板导入自己的数据，导入内容只保存在当前浏览器并可一键清空
- 纸箱与实际托盘尺寸、公差、纸箱间隙、托盘纸箱间隙、托盘间距、退边、缠膜/歪斜余量和集装箱安全余量均可编辑；托盘默认禁止超边，仅在用户明确填写允许超边值后放宽
- 平底托盘自动比较单层高托与上下双层矮托，以全柜纸箱总数优先，数量相同优先少用托盘
- 托盘客户高度区间默认 1200–1800 mm，可按项目修改；默认允许双层，双层时每托仍须满足最低高度
- 托盘外廓柜容利用率默认门槛 70%，低于门槛时自动规划推荐纸箱直装
- 按包装外廓计算包装总材积 CBM
- 箱高固定朝上，底面允许 90° 旋转；每个 SKU 分区可同时混排 0°/90° 落地位，并压缩至满足数量所需的最短纵向外廓
- 对小型高密度平面布局使用精确校正，并校验柜门通过性；水平方向空余超过 150 mm 时必须提示挡固、填充或系固后方可封柜
- 拼柜尾箱按完整外箱尺寸占一个箱位；系统在该 SKU 区末最上层标红，按实际 EA 计数，并要求内部填充、单独封签且禁止承压
- 俯视水平剖面、侧视纵向剖面、箱门端视横向剖面；托盘模式另有单托盘排箱图
- 单托排箱图同步展示实际托盘边界、允许超边边界、0°/90°纸箱、层数、货载外廓与含缠膜余量的装柜规划外廓，并纳入 PDF 报告
- 所有计算在浏览器内完成，不上传业务数据
- 一键输出中文版 / English 正式装柜报告，可打印或保存为 PDF
- 打印前自动复核需求与分柜的 BOX、EA、CBM 合计以及边界、间隙、重叠和高度，并核对报告表格、装载图、横向剖面和分区明细结构；任一校验失败时禁止输出报告
- 交错 SKU 边界使用颜色/代码隔板或隔离片识别；识别隔板不能替代挡木、蜂窝板、支撑、填充或系固等结构性空隙处理
- 可生成服务端 8 位短码网页分享，网址不携带产品参数；接收人可调整数量并重新规划，原始快照不被改写。支持长期有效或 7/30/90/365 天、可选访问码；同时保留打印/另存 PDF
- 报告包含外箱 L × W × H 示意、MEGEE COSPACK 胶带面、装柜编号顺序、0°/90° 数量、水平/纵向/横向剖面及现场复核签字栏
- SAP 逻辑层级与美集品牌视觉结合的清晰响应式界面；390 px 手机端与桌面端均进行页面级横向溢出检查
- 页面标注 Container Planner v2.6.1 与构建源码短提交号，报告附编号、产品导入时间、方案/算法版本与复核状态便于追溯
- 提供 Web App Manifest 与离线应用壳，可从支持的手机或桌面浏览器安装为 PWA；计算与本机方案库不依赖上传服务器

详细发布门槛见 [ACCEPTANCE.md](./ACCEPTANCE.md)。

## 当前发布

- 正式客户入口：<https://container.lostravelerk.com/>
- 已移除 ChatGPT Sites 运行配置，正式构建不会发布到 `chatgpt.site`。
- 正式入口使用由 Cloudflare 管理的自定义域名，避免把 `workers.dev` 或 `pages.dev` 作为客户主入口；具体连通性仍取决于客户所在网络。
- 应用不连接内部 Cost 系统；Excel 解析、装柜计算、方案与人工备注均在当前浏览器完成，不上传业务数据。
- 只有用户主动点击“网页分享”时，才把本次所选 SKU 与方案参数保存为短码快照；完整产品方案库仍仅保存在当前浏览器。分享数据使用独立 D1 表，迁移到阿里云时可备份后保持原域名与 `/s/短码` 路由。

## 本地运行

要求 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 验证

```bash
npm test
npm run lint
npx wrangler deploy --dry-run
```

测试包含生产构建、页面渲染、打印报告元数据和排箱算法边界/重叠检查。

## 计算边界

当前版本输出固定箱高、90° 底面旋转与规则分带约束内的最优工程预估。最终装柜前仍需复核门框、角柱、总载重、轴载、重心、纸箱抗压和供应商实测尺寸。
