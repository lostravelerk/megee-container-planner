# Project rules

Before changing tables, inputs, reports, or Packing Lists, read and follow `docs/table-layout-contract.md`. Alignment is a shared contract, not a per-page styling choice. Keep automated contract tests updated and verify desktop/mobile rendering.

All planning data comes from the current website inputs or the explicitly selected saved snapshot. Never replace SKU quantities, EA/BOX, dimensions, or weights with values from historical examples.

Do not equate geometric feasibility with transport safety or a global optimum. Cross-SKU staggered placement is allowed; support, clearance, separation and load-bearing conditions remain separate checks.
